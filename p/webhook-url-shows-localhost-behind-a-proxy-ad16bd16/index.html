Webhook URL Shows localhost Behind a Proxy

Published
2026-11-02
Checked against
docs.n8n.io
Status
Original

External services call an address that does not exist.

01Symptom and Cause

  • Symptom: The editor shows http://localhost:5678/... as the webhook URL.
  • Why: n8n does not know the public address behind your reverse proxy.

02The Fix

  • Set WEBHOOK_URL to the public HTTPS address and restart.
  • Forward the protocol and host headers in the proxy and enable websocket upgrade.
  • Re-save the webhook in the external service to register the new URL.
