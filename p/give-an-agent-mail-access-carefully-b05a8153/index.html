Give an Agent Mail Access Carefully

Published
2026-11-02
Checked against
docs.n8n.io
Status
Original

An AI Agent with a Gmail tool can read and send. Decide which of those it may do.

01The Risk

  • Problem: An agent with the Send operation can mail the wrong person.
  • Why: The prompt guides the model; it does not enforce limits.

02Safer Setup

  • Give the tool only Get Many and Create Draft.
  • Let a person review drafts before sending.
  • Use a separate Gmail account or label for the agent.
