Least Privilege for AI Agent Tools

Published
2026-11-02
Checked against
docs.n8n.io
Status
Original

An agent with a Gmail tool should rarely be able to send mail.

01Over-Broad Tools

  • Problem: The agent gets every operation of a connected app.
  • Why: A confused or manipulated model uses whatever it is given.

02Tighten It

  • Give each tool only the operations needed, for example read and draft but not send.
  • Use a separate credential with narrow scopes for the agent.
  • Describe in the tool description exactly when it may be called.
