Develop Against Pinned Data

2026-11-02 · digest

Stop calling paid APIs every time you adjust one node.

1. The Waste
• Symptom: Each test run hits the API, burns quota and changes live data.
• Why: Manual execution runs every node again.

2. The Fix
• Run the trigger once, then pin its output with the pin icon.
• Edit and test downstream nodes against the pinned items.
• Pinned data is used in manual runs only. Production runs ignore it.
• Unpin before you activate so nothing stale hides a bug.

Source: n8n Data Pinning Docs
