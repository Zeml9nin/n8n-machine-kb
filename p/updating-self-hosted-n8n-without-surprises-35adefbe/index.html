Updating Self-Hosted n8n Without Surprises

Published
2026-11-02
Checked against
docs.n8n.io
Status
Original

The interface or a node changes after an upgrade and you cannot tell why.

01Before You Update

  • Back up the database and the N8N_ENCRYPTION_KEY. Without the key stored credentials cannot be read.
  • Pin an exact image tag instead of latest.
  • Read the release notes for breaking changes.

02The Routine

  • Update a copy first and open your critical workflows.
  • Update production in a quiet hour and keep the old image for rollback.
  • Check the first scheduled runs in the Executions list.
