Meta Webhook Setup Fails to Verify

2026-11-02 · digest

Instagram and Facebook refuse the callback URL and no execution appears.

1. Why Verification Fails
• Symptom: Meta shows an error when you save the webhook and n8n lists no execution.
• Why: Meta first sends a GET challenge. The Test URL works only while the editor is listening.

2. Checklist
• Use the Production URL and activate the workflow first.
• Accept GET on the Webhook node and answer with the hub.challenge query value.
• Serve the public address over HTTPS with a valid certificate.
• Receive real events on a separate POST webhook.
