Chat Memory for a Telegram Assistant

2026-11-02 · digest

Where conversation history should live and what to key it on.

1. The Setup
• Problem: The bot forgets earlier messages or mixes up two users.
• Fix: Use the chat id as the session key in the agent memory node.

2. Where To Store It
• A spreadsheet works for a demo, but its API quota and speed limit real use.
• For production use a database such as PostgreSQL and keep only the last N messages.
• Do not store personal data you do not need.
