Log Emails to a Sheet Without Duplicates

Published
2026-11-02
Checked against
docs.n8n.io
Status
Original

Polling Gmail and appending rows is simple until the same mail is added twice.

01Symptom and Cause

  • Symptom: The sheet shows repeated rows after a restart or a retry.
  • Why: The trigger can return a message again and Append adds it blindly.

02Fix

  • Store the Gmail message id in a column.
  • Use Append or Update with that id as the matching column.
  • Keep one label or filter so only intended mail is read.
