Error Alerts That Do Not Flood You

2026-11-02 · digest

One broken API can send five hundred identical messages.

1. The Flood
• Problem: Every failed item creates its own chat message and email.
• Why: The error workflow runs once per failed execution.

2. Calm It Down
• Build a key from workflow name and error text and look it up in a small table.
• Alert on the first occurrence and then at most once per hour.
• Send only critical workflows by email and the rest to a log sheet.
