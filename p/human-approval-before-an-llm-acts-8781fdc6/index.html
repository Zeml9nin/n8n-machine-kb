Human Approval Before an LLM Acts

Published
2026-11-02
Checked against
docs.n8n.io
Status
Original

Let the model draft, let a person press the button.

01The Risk

  • Problem: An agent that can send, delete or pay will eventually do it wrongly.
  • Why: Validation in a prompt is a request, not a guarantee.

02The Pattern

  • Put a Send and Wait for Response action (Slack, Telegram, Gmail and others) before every irreversible step.
  • Add an IF node after it: approved continues, rejected stops and logs.
  • Log the model output and the decision so audits stay possible.
