Scoring Items with an LLM

Published
2026-11-02
Checked against
docs.n8n.io
Status
Original

Ranking leads or applications with a model works only if the score is machine-readable.

01Symptom and Cause

  • Symptom: Scores arrive as sentences and the sheet fills with text.
  • Why: A free-form prompt gives free-form answers.

02Fix

  • Ask for JSON with a numeric score and a short reason.
  • Validate it with a Structured Output Parser and retry on failure.
  • Write scores to Google Sheets, then sort and filter there.
