Community Nodes: Install With Care

Published
2026-11-02
Checked against
docs.n8n.io
Status
Original

A new package appears every day. Not all of them deserve your credentials.

01The Risk

  • Problem: An unverified community node runs inside your instance with access to workflow data.
  • Why: It is third-party code, installed from npm.

02Safer Habits

  • Read the repository and the maintainer history before you install.
  • Test in a sandbox instance with synthetic data first.
  • Pin the package version and update on purpose, not automatically.
  • Prefer a built-in node or the HTTP Request node when it covers the case.
