A web form that sends text to a model and returns a result in a few nodes.

01The Pattern

  • Form Trigger collects the input and starts the run.
  • A Basic LLM Chain node holds the prompt and the model sub-node.

02Make It Reliable

  • Make form fields required and cap text length.
  • Add a Structured Output Parser so later nodes get fields, not prose.
  • Answer in the form's final page or send the result by mail.
