Using MCP With n8n Safely

2026-11-02 · digest

Connect models to your tools without handing them the keys.

1. Two Directions
• MCP Client Tool: lets an agent call tools of an external MCP server.
• MCP Server Trigger: exposes selected n8n tools to outside clients.

2. Guardrails
• Expose only the tools the task needs. Each tool is an attack surface.
• Protect the endpoint with authentication and keep it off the open internet where possible.
• Prefer read-only tools and put approval in front of writes.
