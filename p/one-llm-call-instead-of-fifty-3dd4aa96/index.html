One LLM Call Instead of Fifty

Published
2026-11-02
Checked against
docs.n8n.io
Status
Original

Aggregate items first and pay for a single prompt.

01The Waste

  • Symptom: A model node runs once per item and the bill and the latency grow with the list.
  • Why: Nodes process every incoming item separately.

02The Fix

  • Place an Aggregate node before the model to merge items into one list.
  • Ask for one structured answer that covers all entries.
  • Split the answer back with Split Out if later steps need single items.
