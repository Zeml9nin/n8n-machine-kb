Upgrade n8n Without Surprises

Published
2026-11-02
Checked against
docs.n8n.io
Status
Original

A server update that pulls the newest image can change the UI and behavior overnight.

01The Risk

  • Problem: Using latest upgrades n8n on every pull, sometimes mid-project.
  • Why: Nobody chose that version, so nobody tested it.

02Safer Routine

  • Pin the image tag in docker-compose.yml and change it on purpose.
  • Back up the database and the .n8n folder before each upgrade.
  • Read the release notes, then upgrade a copy first.
