Two common data-shape errors and their fixes.

01Array in one item

  • Symptom: An AI node returns one item with leads: [...], so Google Sheets writes only row 1.
  • Fix: Add a Split Out node on leads; each element becomes its own item.

02"[object Object]" in HTTP Request

  • Symptom: The API receives the literal text [object Object].
  • Fix: Send JSON.stringify($json.myObj), or set the body to JSON and pass $json.myObj.
