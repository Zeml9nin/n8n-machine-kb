Form Input to LLM: Validate Both Ends

2026-11-02 · digest

User text goes in, free text comes out, and downstream nodes break.

1. Input Side
• Problem: Form text can carry instructions meant for the model.
• Fix: Keep your rules in the system prompt, pass user text as data and limit its length.

2. Output Side
• Attach a Structured Output Parser so the model returns fields you defined.
• Check required fields with an IF node before writing anywhere.
• Route unparsable answers to a review queue.
