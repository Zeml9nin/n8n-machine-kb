Taming API Rate Limits With Batching

Published
2026-11-02
Checked against
docs.n8n.io
Status
Original

A loop over 500 rows meets a 429 error on row 31.

01Symptom and Cause

  • Symptom: 429 Too Many Requests halfway through a list.
  • Why: n8n sends requests as fast as items arrive.

02Throttle It

  • In the HTTP Request node open Options > Batching and set items per batch and interval.
  • Or use Loop Over Items with a Wait node between batches.
  • Add Retry On Fail with a longer wait for the remaining 429 cases.
